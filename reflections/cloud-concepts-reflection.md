# Cloud Concepts Reflection Paper

## Cloud Services I Use

### 1. Google Drive
- *Service Model*: SaaS - Software as a Service
- *Deployment Model*: Public
- *Why*: Gumagamit ako ng Google Drive para mag-save ng files at mag-collab sa group. SaaS siya kasi di ko na kailangan mag-install ng software, deretso browser lang. Public siya kasi ginagamit siya ng kahit sino sa internet.

### 2. Messenger
- *Service Model*: SaaS - Software as a Service  
- *Deployment Model*: Public
- *Why*: Ginagamit ko si Messenger araw-araw pang chat. SaaS kasi app siya na hosted ni Meta at di ko kailangan i-manage yung server. Public kasi open siya sa lahat ng tao.

### 3. GCash
- *Service Model*: SaaS - Software as a Service
- *Deployment Model*: Public
- *Why*: Ginagamit ko si GCash pang bayad at transfer ng pera. SaaS kasi through app ko siya na-access at sila na bahala sa maintenance. Public kasi available siya sa lahat ng users.

## Git & GitHub for Cloud Projects

Version control is very important when working with cloud infrastructure because it helps us track every change made to our code and configuration files. In cloud projects, madalas may maraming nagtatrabaho at nagbabago ng settings. Kung walang Git, mahirap malaman kung sino ang nagbago at paano ibalik kung may nagkamali.

GitHub helps teams collaborate by allowing multiple people to work on the same project without overwriting each other's work. We can use branches to work on new features separately, then merge them when ready. GitHub also tracks all changes with commit history, so we can see who did what and when. This prevents errors because we can easily revert to previous versions if something breaks. For cloud resources, this is critical because one wrong command can affect many users. With GitHub, teams can review code before merging, document changes, and ensure the cloud infrastructure stays stable and secure.

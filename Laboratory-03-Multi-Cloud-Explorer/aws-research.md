## Four Core Services
1. *Compute*: Amazon EC2 - Virtual servers
2. *Storage*: Amazon S3 - Object storage
3. *Database*: Amazon RDS - Relational Database
4. *Networking*: Amazon VPC - Virtual Private Cloud

## Three Advantages

2. Extensive global infrastructure
3. Pay-as-you-go pricing with free tier

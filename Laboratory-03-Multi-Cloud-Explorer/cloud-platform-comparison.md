## Analysis Questions
1. *Which cloud provider offers the broadest range of services?*  
   AWS offers the broadest range of services because it has been in the market the longest and has over 200 services. It covers almost every cloud need from computing to IoT.

2. *Which provider best integrates with Microsoft technologies?*  
   Microsoft Azure integrates best with Microsoft technologies because it is made by Microsoft. It has native support for Windows Server, Active Directory, and Microsoft 365.

3. *Which provider is strongest in Artificial Intelligence and Kubernetes?*  
   Google Cloud Platform is strongest in AI and Kubernetes because Google created TensorFlow and Kubernetes. GCP also has TPUs which are made specifically for AI.

4. *Which cloud platform would you personally choose and why?*  
   I would personally choose AWS because it has the largest community and most job opportunities. It also has the most documentation and tutorials which helps beginners like me learn faster.

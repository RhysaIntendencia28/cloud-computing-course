## 1. Brief Overview
Google Cloud Platform (GCP) is a suite of cloud computing services offered by Google. It provides infrastructure, platform, and serverless computing environments. GCP is known for its strength in data analytics, machine learning, and Kubernetes. It powers Google's own products like YouTube, Gmail, and Google Search.

## 2. Global Infrastructure
GCP has 37 regions, 112 zones, and over 200 Points of Presence worldwide as of 2025. Google owns its own global fiber network which makes data transfer very fast and secure. It also has submarine cables to connect continents.

## 3. Cloud Management Console
The Google Cloud Console is where you manage all GCP resources.
![GCP Console](./screenshots/gcp-homepage.png)

## 4. Four (4) Core Services
1. *Compute:* Compute Engine - for virtual machines
2. *Storage:* Cloud Storage - for object storage like images and files
3. *Database:* Cloud SQL / BigQuery - for relational and big data analytics
4. *Networking:* VPC Network - for virtual private cloud and networking

## 5. Three (3) Advantages
1. *Leader in AI and Machine Learning:* Has TensorFlow, Vertex AI, and custom TPUs for AI workloads.
2. *Best Kubernetes Support:* Kubernetes was originally created by Google. GKE is the most mature K8s service.
3. *Strong Data Analytics:* BigQuery is one of the fastest and most powerful data warehouses in the cloud.

## 6. Typical Enterprise Use Cases
1. *Big Data and Analytics:* Companies use BigQuery to analyze huge amounts of data.
2. *AI/ML Applications:* Used by companies to build and deploy AI models.
3. *Containerized Applications:* Best platform for running Docker and Kubernetes.

# Client Recommendations - Rhysaintendencia

## Client A - Startup Company
*Recommended Platform:* AWS
*Explanation:* AWS is the best choice for startups because of its free tier and low cost. Startups need to save money at first but also need to scale fast. AWS has many startup programs and credits that can help.
*3 Services:* 1. EC2 2. S3 3. Lambda

## Client B - University
*Recommended Platform:* Microsoft Azure
*Explanation:* Azure is the best for the university because they already use Windows Server, Microsoft 365, and Active Directory. Migrating to Azure will be easier and cheaper since everything is already integrated.
*3 Services:* 1. Azure Virtual Machines 2. Azure Active Directory 3. Microsoft 365

## Client C - AI Research Company
*Recommended Platform:* Google Cloud Platform
*Explanation:* GCP is the best for AI research because Google is the leader in AI and Machine Learning. They offer Vertex AI and TPUs which are needed for high-performance computing for AI models.
*3 Services:* 1. Vertex AI 2. Compute Engine 3. BigQuery

## Client D - Global E-Commerce Company
*Recommended Platform:* AWS
*Explanation:* AWS is best for global e-commerce because it has the most regions worldwide. This ensures low latency for customers. AWS also has great auto-scaling and CDN through CloudFront for high traffic.
*3 Services:* 1. EC2 Auto Scaling 2. CloudFront 3. DynamoDB

## Multi-Cloud Decision Matrix
| Business Requirement | Recommended Platform | Justification |
| --- | --- | --- |
| Startup Company | AWS | Low cost + free tier + easy scaling |
| Enterprise Organization | Microsoft Azure | Strong enterprise support and security |
| Microsoft Environment | Microsoft Azure | Native integration with MS products |
| AI / Machine Learning | Google Cloud Platform | Best AI tools and TPUs |
| Kubernetes Deployment | Google Cloud Platform | Kubernetes was created by Google |
| Global Web Application | AWS | Largest global infrastructure |
